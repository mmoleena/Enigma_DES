# Securing Data in Cloud Environment using Enigma & DES Combination Encryption

## Overview
This project enhances pre-existing encryption systems by addressing critical flaws in older methods. The combination of bit-encryption (Enigma) and block-encryption (DES) creates a robust solution for securing data. The objective is to demonstrate the usefulness of double encryption in modern systems by layering multiple encryption mechanisms to improve security.

## Project Modules
The project is divided into four key modules:

### 1. Enigma
This module implements an upgraded version of the Enigma encryption algorithm. It includes both encryption and decryption mechanisms inspired by the WWII military Enigma machine.

### 2. DES (Data Encryption Standard)
The DES module primarily encrypts the decryption key generated by the Enigma module, ensuring the security of key exchange.

### 3. SMTP Mailing
This module incorporates mailing services to securely transmit both the ciphertext and the decryption key to the intended recipient using SMTP protocol.

### 4. Cloud Storage
The Cloud module handles secure data storage on a private cloud. The cloud system is implemented on a Kali Linux machine designed to offer a secure environment for storing encrypted data.

## Limitations
This project is a sample and could contain flaws. The idea behind using double encryption is to enhance security in scenarios where additional layers of protection are required. By managing two sets of keys and performing two rounds of encryption, the system becomes more complex, but it also improves resilience against attacks.

### Enigma Considerations
While the Enigma algorithm can be hardcoded into software and used in modern encryption techniques, it has limitations. Enigma's keyspace (the number of possible encryption settings) is much smaller compared to modern standards. Current encryption algorithms use 128-bit, 192-bit, or 256-bit keys, while Enigma's effective keyspace is significantly smaller, limiting its standalone use in high-security environments.

---

## Conclusion
This project serves as a conceptual demonstration of how combining older encryption techniques, such as Enigma, with more modern encryption standards, like DES, can provide added security. By leveraging double encryption, systems can introduce additional layers of complexity, making them more secure for data storage and transmission in cloud environments.
